# Bengali Smart Calculator & Loan EMI Calculator (বাংলা ক্যালকুলেটর)

একটি আধুনিক ও উন্নত বাংলা ক্যালকুলেটর এবং লোন/ইএমআই ক্যালকুলেটর অ্যান্ড্রয়েড অ্যাপ (Jetpack Compose & Material 3)।

## 📱 কীভাবে GitHub থেকে APK ফাইল ডাউনলোড করবেন (How to Download APK):

GitHub-এ এই রিপোজিটরিটি পুশ বা এক্সপোর্ট করার পর স্বয়ংক্রিয়ভাবে (GitHub Actions-এর মাধ্যমে) APK তৈরি হয়ে যায়। আপনি খুব সহজেই সরাসরি ডাউনলোড করতে পারবেন:

1. **GitHub রিপোজিটরিতে যান:**
   - ব্রাউজারে আপনার GitHub রিপোজিটরি ওপেন করুন।

2. **Actions ট্যাবে ক্লিক করুন:**
   - রিপোজিটরির উপরের মেনুবার থেকে **`Actions`** ট্যাবে ক্লিক করুন।

3. **সর্বশেষ Workflow Run সিলেক্ট করুন:**
   - **`Build Android APK`** নামের তালিকার সবচেয়ে উপরের (সবার শেষের) রানে ক্লিক করুন (সবুজ টিক মার্ক থাকবে)।

4. **Artifacts থেকে APK ডাউনলোড করুন:**
   - পেইজটির নিচের দিকে স্ক্রোল করলে **`Artifacts`** সেকশন দেখতে পাবেন।
   - সেখানে থাকা **`Bengali-Calculator-APK`** ফাইলের উপর ক্লিক করুন।
   - একটি ZIP ফাইল ডাউনলোড হবে। আনজিপ করলেই পেয়ে যাবেন ইন্সটলযোগ্য **`app-debug.apk`** ফাইল।

5. **ফোনে ইন্সটল করুন:**
   - `.apk` ফাইলটি আপনার অ্যান্ড্রয়েড ফোনে পাঠিয়ে ইন্সটল (Install) করে নিন।

- Google AI Studio-র উপরের ডানপাশের **Settings (সেটিংস)** বা **Export** মেনু থেকে **"Download APK"** বা **"Export as ZIP"** করতে পারেন।

## 🛠️ ফিচারসমূহ (Features):
- 🔢 **টোকেন এডিটর সহ সাধারণ ক্যালকুলেটর:** যেকোনো লম্বা হিসেবের মাঝের সংখ্যা (যেমন: ১৫০ + ২৩০ + ৩০০ এর যেকোনো অংশ) সরাসরি এডিট করার সুবিধা।
- 📜 **ফুল-স্ক্রিন স্ক্রোলেবল ক্যালকুলেশন হিস্ট্রি:** বিগত ৬ মাসের হিসাবের তারিখ ও বিস্তারিত ইতিহাস দেখা ও ফিল্টার করার সুবিধা।
- 💰 **লোন ও ইএমআই ক্যালকুলেটর:** মাসিক কিস্তি (EMI), মোট সুদ (Total Interest Payable) এবং মূলধনসহ মোট পরিশোধিত টাকার স্পষ্ট হিসাব ও ব্রেকডাউন।
- ৳ **বাংলাদেশী টাকা (৳) কারেন্সি সিম্বল সাপোর্ট:** নির্ভুল কারেন্সি ফরম্যাটিং।
